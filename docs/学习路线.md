# 学习路线

| 项目 | 先能解释什么 | 再实际做什么 |
|---|---|---|
| 信标 | 字节怎样组帧、在哪解析、参数何时保存 | F407 点灯/节拍 → 串口 → 组帧与异常输入 |
| LFM | 采样如何经过滤波、降采样、相关和峰选择 | 导出输入、运行 PC C 版、逐项对照 |
| 红外 | 输入输出、骨干适配、训练与推理 | 最终权重单图推理，解释 TTA 开销 |
| 遥操作 | 主端/从端/Web 如何分工与通信 | 主从连通，再单测预约与摄像头 |
| 灵犀 | 终端采集、路由、模型与动作分工 | 离线回归 → 服务配置 → 调试包与真机 |

每次记录实际改动、验证方法、未验证项。面试表达以实际完成范围为准。
嵌入式面试先掌握 C、指针/数组、内存边界、时钟、GPIO、串口中断、状态机、Flash 和调试，再扩展各项目。

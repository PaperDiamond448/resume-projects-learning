# F103 复刻短基线信标固件 · 实验总纲

> 目的：板子（STM32F427 真机）不在手边时，用手头的 F103C8T6 套件，在面包板上**复刻信标固件的软件架构**。
> 学的不是“点灯”，是这套商业固件的**结构和工程决策**。做完第四个实验，你手里就是一台“桌面信标”。
>
> **另有实验五和实验六两个扩展实验**：`实验五_阵列测向/` 是导师要求的“阵列信号处理 + 硬件结合”作业，做2元阵TDOA声源方向估计，直接对应短基线定位接收端的数学核心；`实验六_人机交互控制台/` 则把旋转编码器、第二个电位器、OLED和有源蜂鸣器组合成一个可操作的小设备，为后续舵机和电机闭环实验铺路。两个扩展实验都由独立的 `main.c` + `接线与说明.md` 组成。

---

## 一、为什么是这 4 个主线实验（7→4 的合并）

| 实验 | 同时练 | 复刻固件里的什么 |
|---|---|---|
| **实验一 · 系统骨架** | 非阻塞 LED 灯效 + 按键 EXTI 中断 + SysTick 1Hz 心跳 + CPU 占用率 + 串口打印调试 | `main()` 的 `while(1)` 前后台结构、`OnEchoRTC()` 心跳链、`LedShine()`、CPU 占用率测量、调试串口 |
| **实验二 · 上位机协议** | 串口逐字节组帧状态机 + `$A,B,C,D*` 协议 + 命令分发 switch | `USART_IRQHandler → Comm_GetFrameMsg → OnEchoPCLINK` 那条命令链、`COMM_OBJECT`、广播地址、收命令清看门狗 |
| **实验三 · 传感采集链** | ADC + DMA 循环 + 滑动平均滤波 + 标定限幅；软件 I2C 读 MPU6050 | `ADC_operate.c` 三段式（轮询→DMA→滤波）、传感器“采样→滤波→标定→限幅”流水线、`ms5837.c` 软件 I2C 链路 |
| **实验四 · 桌面信标（毕设）** | 蜂鸣器 Chirp 发生（频率字/步进字）+ 参数掉电保存 + 软硬看门狗 + 集成前三个 | `iBeacon_SetEmitParam()` 类 DDS 波形计算、`g_stSys` 参数存 Flash、标志位延迟写、`RTC_COUNTER` 分级看门狗 |
| **实验六 · 人机交互控制台（扩展）** | 旋转编码器正交解码 + ADC电位器 + OLED菜单 + 有源蜂鸣器报警 | 把“输入→参数→显示→输出”连成一个可操作设备，为后续执行器和闭环控制做准备 |

**合并原则**：后一个实验复用前一个的成果——实验二的串口在三、四里继续当“上位机”，实验一的心跳和灯效一直留着。所以你是在**滚雪球**，不是做四个孤立的 demo。

## 二、统一引脚分配表（一次接好，四个实验不用重新�接线）

按这张表把器件接到面包板，从实验一到实验四逐步用上，**中途不需要拔线重接**。

| 功能 | F103 引脚 | 接到 | 哪个实验开始用 |
|---|---|---|---|
| 板载 LED | PC13 | （板载，低电平点亮） | 一 |
| 用户按键 | PA0 | 按键一端→PA0，另一端→GND | 一（四里当“PPS 秒脉冲”） |
| 调试/上位机串口 TX | PA9 (USART1_TX) | USB转TTL 的 **RXD** | 一（打印），二（双向） |
| 调试/上位机串口 RX | PA10 (USART1_RX) | USB转TTL 的 **TXD** | 二 |
| 电位器 | PA1 (ADC1_IN1) | 中间脚→PA1，两边→3.3V/GND | 三 |
| 光敏传感器 | PA2 (ADC1_IN2) | 模拟输出→PA2 | 三 |
| 热敏传感器 | PA3 (ADC1_IN3) | 模拟输出→PA3 | 三 |
| 软件 I2C SCL | PB8 | OLED 和 MPU6050 的 SCL（共用） | 三（OLED 可选，一就能用） |
| 软件 I2C SDA | PB9 | OLED 和 MPU6050 的 SDA（共用） | 三 |
| 无源蜂鸣器 | PB1 (TIM3_CH4) | 蜂鸣器+→PB1，-→GND | 四 |
| W25Q64 CS | PA4 (SPI1_NSS) | Flash 的 CS | 四 |
| W25Q64 SCK | PA5 (SPI1_SCK) | Flash 的 CLK | 四 |
| W25Q64 MISO | PA6 (SPI1_MISO) | Flash 的 DO | 四 |
| W25Q64 MOSI | PA7 (SPI1_MOSI) | Flash 的 DI | 四 |

> 接线总原则：所有模块的 **GND 必须和开发板 GND 接到面包板的同一条地线**。USB转TTL 用 USB 供电时，TTL 的 5V/3.3V **不要**再接到已经被 USB 供电的开发板上，只接 GND + TX + RX 三根。

> 实验六是独立扩展实验，不纳入前四个主线实验的“一次接好、不重接”引脚表：它把第二个电位器接到 PA4，把编码器 A/B/SW 接到 PB10/PB11/PB12，并继续使用 PB1 接有源蜂鸣器。运行实验六时先断开实验四的 W25Q64，避免 PA4 同时被当作 ADC 输入和 Flash 片选。

## 三、⚠️ 一个必须先知道的器件坑：蜂鸣器

你套件里是 **有源蜂鸣器**——它内部自带振荡电路，**一通电只会响一个固定频率**，无法做频率扫描。
而实验四的核心（信标的 Chirp/LFM 波形）恰恰需要**改变频率**，必须用 **无源蜂鸣器**（约 1 元，某宝/电子城都有）。

- **想完整做实验四的“频率扫描”**：买一个**无源蜂鸣器**，接 PB1。
- **暂时只有有源蜂鸣器**：实验四可以先只做“PPS 触发 → 发一个固定时长的脉冲”这部分（练发射时序、脉宽、死区时间），频率扫描等无源蜂鸣器到货再补。

## 四、器件清单（按实验）

- **实验一**：开发板、USB转TTL、（板载 LED 和按键即可，外加面包板+杜邦线）。按键若用外接：按键包 1 个。
- **实验二**：实验一全部（不加新器件，纯软件）。
- **实验三**：+ 电位器、光敏传感器、热敏传感器、MPU6050；OLED（可选，做显示更直观）。
- **实验四**：+ 无源蜂鸣器（见上面的坑）、W25Q64 存储模块。

## 五、怎么用这套实验才不白做

1. **每个实验先读 `接线与说明.md`，再读 `main.c` 顶部的“对应固件”注释**，知道自己在复刻哪一段真代码。
2. **每个实验末尾都有“验收标准”**：做到那个现象，才算过。
3. 做完一个回来找我要下一个；卡住了把现象告诉我，我帮你定位。
4. 全部做完，照 `实验四` 里的“桌面信标整合清单”把四个拼成一个系统——那就是你答辩时最硬的工作量证明。

> 学习心法：别顺着代码一行行读，**带着“这条命令从串口进来，怎么一路走到蜂鸣器响”这种问题去追链路**；再追问每个“为什么不”（为什么不用 RTOS、为什么中断里不写 Flash、为什么忙等都带超时）。答案就是工程经验。

# 实验一 · 系统骨架（前后台 + 中断 + 心跳 + CPU占用率）

## 1. 这个实验复刻固件的什么

| 本实验做的事 | 对应真固件 |
|---|---|
| `main()` 里 `while(1)` 不停转，干活靠“标志位” | `USER/main.c` 的主循环 + `m_bForceStore` 等标志位延迟执行 |
| SysTick 每秒中断一次，做“心跳” | 真固件用 RTC 每秒唤醒做 `OnEchoRTC()` 心跳链（这里用 SysTick 替代，原理一样） |
| 主循环空转计数，每秒折算 CPU 占用率 | `main.c` 的 `m_uCpuIdle += step` + `OnEchoRTC` 里算 `m_fCpuIdle` |
| 按键中断只置标志，真正干活在主循环 | 中断 ISR 置标志、后台处理——无 RTOS 系统的“任务调度”精髓 |
| LED 非阻塞闪烁（不用 delay 卡住 CPU） | `main.c` 的 `LedShine()` |
| 串口打印调试信息 | 固件的 `DEBUG_Comm` 调试串口 + `printf` 重定向 |

**一句话**：这一个实验，就把信标固件的“骨架”——前台中断 + 后台主循环 + 心跳 + 负载监控——全搭起来了。

## 2. 器件清单（实验一）

| 器件 | 数量 | 用途 | 必须 |
|---|---|---|---|
| STM32F103C8T6 开发板 | 1 | 主角 | ✅ |
| Micro USB 数据线 | 1 | 给板子供电 | ✅ |
| 面包板 | 1 | 插按键、布线 | 装按键时 |
| 按键（按键包里拿1个） | 1 | 接 PA0，切换闪灯速度 | 测按键时 |
| 杜邦线 | 几根 | 连线 | 同上 |
| USB转TTL **或** OLED屏 | 1 | 看心跳数字（二选一） | 看数字时 |

> ⚠️ 注意：蓝丸板上**没有用户按键**，只有 RESET 复位键。按键要自己从按键包接到 PA0。

## 3. 接线（分三步，逐步加）

### 第①步 · 零接线，先看 LED 闪
只用 Micro USB 给板子供电 → 板载 LED(PC13) 开始 0.5s 闪一次。
这一步**不接任何线**就能验证程序在跑。

### 第②步 · 加按键（PA0 ←→ GND）
面包板基础：**同一竖列的 5 个孔内部连通**，中间凹槽把上下两半隔开；开发板骑在凹槽上插下去。
- 按键 4 脚跨凹槽插好。
- 杜邦线①：开发板 **PA0** 那列空孔 → 按键一只脚。
- 杜邦线②：按键**对角线**那只脚 → **GND**（板上标 `G` 的引脚）。
- 按下 = PA0 接到 GND。

> 引脚照**丝印**找（每个脚旁印了 PA0/PA9/PB8/G/3.3），别数孔。

### 第③步 · 看心跳数字（USB转TTL 或 OLED，二选一）

**方案A · USB转TTL（电脑串口看文字），只接 3 根：**

| USB转TTL | 接到开发板 | 说明 |
|---|---|---|
| GND | G (GND) | 必须共地 |
| TXD | PA10 (USART1 RX) | TX 接对方 RX |
| RXD | PA9 (USART1 TX) | RX 接对方 TX |

- **TX/RX 必须交叉**：TX 是“嘴/发送”，RX 是“耳朵/接收”，我的嘴对你的耳朵，所以一方 TX 接另一方 RX。
- ⚠️ USB转TTL 的 **3V3/5V 别接**（板子已被 USB 供电，再接会打架）。
- 串口助手设 **115200, 8N1**。

**方案B · OLED（小屏看，全直连不用交叉，新手更省心）：**

| OLED | 接到开发板 |
|---|---|
| GND | G (GND) |
| VCC | 3.3 |
| SCL | PB8 |
| SDA | PB9 |

OLED 代码见同目录《接线_OLED补充.md》。

## 4. Keil 工程设置（重要）

1. 用任意一个 **STM32F103C8 + 标准外设库(StdPeriph/SPL)** 的空工程模板（你主项目里的 F4 也是 SPL，F1 的模板网上一搜一堆）。
2. 把本目录的 `main.c` 替换进去。
3. **Options → Target → 勾选 "Use MicroLIB"**（否则 `printf` 不输出，会卡在半主机模式）。
4. 确认 `system_stm32f10x.c` 配的是 72MHz（HSE 8MHz×9，蓝丸默认）。没有外部晶振也能跑，只是变 8MHz，打印里会显示当前主频。

## 5. 怎么验证（验收标准）

1. 打开串口助手，**115200, 8N1**。
2. 上电后每秒收到一行心跳，类似：
   ```
   [HeartBeat] t=12s  SysClk=72MHz  CPU=2%  LED=500ms
   ```
3. **板载 LED 以 500ms 周期闪烁**（亮灭各半秒）。
4. **按一下按键**：串口打印 `>> KEY pressed, blink -> 100ms`，LED 改为快闪；再按一下切回 500ms。
5. ✅ 全部出现 = 通过。你已经拥有一个“中断在前台、任务在后台、每秒报告自身状态”的系统骨架。

# 实验六 · 人机交互控制台

## 1. 这个实验做什么

前面的实验已经能完成“采集数据、串口打印、控制蜂鸣器”。这次把它们组合成一个真正可以操作的小设备：

```text
旋转编码器 ──修改参数──┐
编码器按键 ──切换菜单──┤
                       ↓
                 STM32F103C8T6
                       ↑
第二个电位器 ──模拟输入─┘
                       ↓
              OLED显示 / 蜂鸣器报警 / LED状态
```

本实验练习：

- 旋转编码器 A/B 两相正交解码；
- 编码器按键消抖和菜单切换；
- ADC 读取第二个电位器并转换为毫伏；
- 参数限幅和非阻塞任务；
- OLED 与串口同时显示运行状态；
- 有源蜂鸣器低电平触发报警。

它是后续“舵机控制”和“电机闭环调速”的人机交互基础。

## 2. 工程文件

本目录提供：

- `main.c`：实验六完整代码；
- `接线与说明.md`：接线、编译、验收和思考题。

OLED 驱动沿用实验一。建立 Keil 工程时，把实验一目录中的以下文件加入工程：

```text
实验一_系统骨架/oled.c
实验一_系统骨架/oled.h
实验一_系统骨架/oledfont.h
```

同时沿用实验一的 CMSIS、启动文件和标准外设库。`main.c` 需要 `stm32f10x_adc.c`、`stm32f10x_gpio.c`、`stm32f10x_exti.c`、`stm32f10x_usart.c` 等 SPL 源文件。

Keil 中勾选 `Use MicroLIB`，串口设为 115200、8N1。

## 3. 器件清单

| 器件 | 数量 | 用途 |
|---|---:|---|
| STM32F103C8T6 开发板 | 1 | 主控制器 |
| 旋转编码器模块 | 1 | 修改参数、切换编辑项 |
| 电位器 | 1 | 模拟传感器输入 |
| OLED 128×64 | 1 | 显示菜单和状态 |

这里使用的是套件里的**第二个电位器**。实验三正在使用的第一个电位器可以保留原接线，不要把两个滑片短接。

## 4. 引脚分配与接线

### 4.1 OLED

| OLED引脚 | 开发板 |
|---|---|
| GND | GND |
| VCC | 3.3V |
| SCL | PB8 |
| SDA | PB9 |

OLED 和实验三使用同一套软件 I2C 驱动。

### 4.2 旋转编码器

| 编码器引脚 | 开发板 | 说明 |
|---|---|---|
| `+` / `VCC` | 3.3V | 不建议接5V |
| `GND` | GND | 共地 |
| `CLK` / `A` | PB10 | A相，EXTI10 |
| `DT` / `B` | PB11 | B相，EXTI11 |
| `SW` | PB12 | 按键，按下接地，EXTI12 |

代码使用 PB10、PB11 的双边沿中断进行正交解码，PB12 的下降沿作为按键事件。

### 4.3 第二个电位器

| 电位器引脚 | 开发板 |
|---|---|
| 一端 | 3.3V |
| 另一端 | GND |
| 中间滑片 | PA4 |

PA4 是 `ADC1_IN4`。本实验为独立扩展实验，PA4 在这里不接实验四的 W25Q64 CS；运行实验六时先断开 W25Q64。

### 4.4 有源蜂鸣器

| 蜂鸣器模块引脚 | 开发板 |
|---|---|
| VCC | 按模块标注供电，优先3.3V |
| GND | GND |
| S / SIG | PB1 |

套件里的有源蜂鸣器模块已经实测为**低电平触发**：PB1 输出低电平时响，输出高电平时关闭。代码设计为“停900ms、响100ms”，不会持续长响。

## 5. 实际操作

### 第一步：上电检查

下载程序后，OLED 应先显示：

```text
F103 LAB6
ROTARY CONSOLE
PRESS TO EDIT
BOOT OK
```

串口应输出：

```text
==== F103 Lab6: Human-Machine Console ====
Encoder PB10/PB11/PB12, pot PA4, buzzer PB1
```

### 第二步：调节LED闪烁周期

初始编辑项是 `SET:LED`。

- 顺时针旋转编码器：LED周期增加，每格增加50ms；
- 逆时针旋转编码器：LED周期减少，每格减少50ms；
- 可调范围：100～1000ms；
- OLED 第二行显示当前周期。

如果顺逆时针方向相反，不是硬件坏了，把编码器 A、B 两线对调即可。

### 第三步：切换报警阈值

按一下编码器中间的按键，编辑项从 `SET:LED` 切换到 `SET:ALARM`。

- 旋转编码器：修改报警阈值；
- 每格增加或减少100mV；
- 可调范围：300～3200mV；
- OLED 第二行显示当前报警阈值。

### 第四步：用电位器触发报警

旋转第二个电位器：

```text
电位器电压 >= 报警阈值
              ↓
          ALARM:ON
              ↓
       LED快速闪烁 + 蜂鸣器间歇响
```

OLED 第五行显示当前电位器电压，第七行显示 `ALARM:ON` 或 `ALARM:OFF`。

## 6. 验收标准

- OLED 能正常显示启动信息和运行状态；
- 编码器顺、逆时针旋转时，参数只向对应方向变化；
- 按下编码器按键后，编辑项在 LED 周期和报警阈值之间切换；
- 电位器电压能在约 0～3300mV 之间变化；
- 电位器电压超过阈值后，OLED 显示 `ALARM:ON`；
- 报警时 LED 变成快速闪烁，蜂鸣器间歇鸣叫；
- 串口每秒打印一次当前参数和报警状态；
- 调整参数或触发报警时，主循环没有使用长时间 `delay` 卡住。

全部完成，说明你已经把“输入、参数、显示、输出、报警”五个环节连成了一条完整的人机交互链。

## 7. 常见问题

### 编码器只能加不能减，或者方向反了

先确认 `CLK` 接 PB10、`DT` 接 PB11。方向相反时直接交换 A、B 两线即可。

机械编码器有抖动，偶尔多一格是正常现象。代码使用四边沿状态表过滤大部分非法跳变；如果模块质量较差，可以在后续版本增加更严格的软件消抖。

### 蜂鸣器一直响

先断开 PB1，确认模块的 `S/SIG` 脚没有接错。套件模块是低电平触发，代码默认高电平关闭。如果你的模块是高电平触发，需要把 `Task_Alarm()` 中的高低电平逻辑反过来。

### 电位器数值不变

确认中间滑片接 PA4，两端分别接 3.3V 和 GND；不要把滑片接到 5V。PA4 在本实验里是 ADC 输入，不是普通数字输出。

### OLED 不亮

检查 PB8/PB9 是否接反、OLED 地址是否为 `0x78`，并确认 `oled.c`、`oled.h`、`oledfont.h` 都加入了 Keil 工程。

## 8. 做完想一想

- 为什么编码器 A/B 需要两路信号，而普通按键只需要一路？
- 为什么编码器中断里只产生 `g_encStepEvent`，不直接刷新 OLED？
- 为什么报警阈值要做上下限保护？
- 如果把电位器换成反射红外传感器的 AO，软件哪一层可以不改？
- 如果把蜂鸣器报警换成舵机动作，哪些部分仍然可以复用？
- 如果 OLED 刷屏函数本身比较慢，编码器快速旋转时为什么可能丢步？应该如何改成定时刷新或用更高效的显示缓冲？

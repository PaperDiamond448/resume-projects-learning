# 信标第一课：从一条串口命令开始

本课先读一条通信链，不要求掌握整个水声系统。目标是自己解释一条命令进入固件后发生了什么，为下一步做 PC 协议练习准备。

## 1. 先分清四件事

1. 串口把字节送进来。一次收到一个字符，不代表已经收到一整条命令。
2. 组帧函数判断命令从哪里开始、到哪里结束，把字节存入缓冲区。
3. 解析函数把字符形式的字段转成设备地址、命令号和参数。
4. 分发函数根据命令号执行对应操作，有些耗时操作通过标志交给主循环。

例如源码描述的格式是 `$A,B,C,D*`：A 是设备地址，B 是命令号，C、D 是参数。这里不假定某个命令号对应具体硬件动作；需要再查命令定义。

## 2. 看串口中断入口

打开 [stm32f4xx_it.c](../reference_f427/USER/stm32f4xx_it.c)，沿 `USART2_IRQHandler` 查找 `Comm_GetFrameMsg` 和 `OnEchoComm2`。

这一入口说明：收来的字节交给组帧函数；组帧函数返回帧已就绪时，入口继续调用上层响应。由此应追踪实际调用位置，不笼统地说“所有命令都在主循环处理”。

这一步需要回答：读取串口数据的语句是哪句？接收的是一个字节还是整帧？调用上层响应时是否仍在中断上下文？

## 3. 看组帧函数保存了什么

打开 [Comm_GetFrameMsg](../reference_f427/USER/Comm_operate.c)。重点只看四个成员：

| 成员 | 本函数里的作用 |
|---|---|
| `chRxBuf` | 存放正在接收的帧内容 |
| `uCommRx` | 下一次写入的位置 |
| `nRFlag` | 是否处于接收帧内容的状态 |
| `bRdy` | 是否已经得到可以交给上层的完整帧 |

源码遇到 `$` 时把接收位置重置为 0，并进入接收状态；这一版本没有把 `$` 存进 `chRxBuf`。普通字符随后逐个写入。遇到 `*` 时，在容量条件满足的情况下追加 `*`、回车、换行和字符串结束符，将 `bRdy` 置为真。

所以，若逐字节输入 `$1,2,3,4*`，上层收到的缓冲内容为 `1,2,3,4*\r\n`，最后还有 C 字符串结束符。起始符用于控制接收状态，并未保留在正文中。

需要自己画一个状态表：输入 `$`、`1`、`,`、`2`、`,`、`3`、`,`、`4`、`*` 时，分别记录位置计数、接收标志和就绪标志。随后检查超长输入与新的 `$` 如何处理。

## 4. 看地址过滤与命令分发

打开 [OnEchoPCLINK](../reference_f427/USER/main.c)，跟到 `PCLINK_DecodeCmd`。

这里先检查对象是否有效、初始化是否结束和帧是否就绪。解析成功后，它检查设备地址：地址 0 是通配地址，或者地址等于本机地址时，才继续处理。随后根据命令号执行对应操作。

这一层要分清“帧完整”和“命令有效”：有完整结束符，不代表字段正确、地址匹配或参数合法。两种检查不能合并理解。

## 5. 看参数为什么要延迟保存

打开 [main.c](../reference_f427/USER/main.c)，看 `m_bForceStore` 分支，再看 [SysParam_Save](../reference_f427/USER/PCLink_operate.c)。

主循环观察到保存标志后，清除标志并执行参数保存。接着在 `PCLink_operate.c` 中查找哪些命令会设置 `m_bForceStore`。你需要沿具体命令核对，不能假定所有参数修改都会自动落盘。

把“修改内存里的当前参数”和“写入 Flash 后重启仍保留”分开理解。Flash 擦写需要时间，放在主循环处理可以避免在相关命令响应里直接执行这一耗时操作；整体响应是否及时，还要结合执行耗时与实际测试判断。

## 6. 本课交付，不要求背整份工程

- 一张文字调用链：串口中断、组帧、解析、地址判断、分发、保存标志、主循环写 Flash。
- 一张 `$1,2,3,4*` 的逐字节状态表。
- 一条实际参数命令的追踪记录：命令定义在哪里、修改了哪个字段、是否设置保存标志、由谁应答。
- 五个自己的问题及答案：起始符是否进缓冲？中断里做了什么？完整帧为什么仍可能无效？超长输入如何恢复？不保存就断电会发生什么？

完成后，用自己的话讲清上述链路，再进入 PC 端组帧复现和异常输入测试。现阶段不要求描述 FPGA 算法、声学定位公式或整个系统的独立研发。

## 整理时核对

部分参数通过 m_bForceStore 交给主循环保存；设置地址的命令仍直接调用 SysParam_Save。沿具体命令追踪，不能概括成所有 Flash 操作都已移出中断。

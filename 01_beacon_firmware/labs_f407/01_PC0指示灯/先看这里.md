# 第一课：让 F407 的 PC0 指示灯闪烁

适用：照片中的鹿小班 LXB407VE-P1-V2.0，芯片顶面标注 STM32F407VGT6。
工程芯片：STM32F407VG；编译器：Arm Compiler 6.22；GPIO 使用标准外设库。

## 现在怎么操作

1. 退出旧 F103 工程。若 Keil 尚未刷新新安装的 F4 支持包，重开 Keil。
2. 双击本文件夹中的 F407_PC0_Blink.uvprojx。
3. 魔法棒 -> Device：检查 STM32F407VG；Target 页：Cortex-M4，RAM 128KB、Flash 1MB。
4. Debug：ST-Link Debugger -> Settings，Port=SW，Connect=Normal。核对 SW Device 能识别。
5. Flash Download 页：算法应为 STM32F4xx 的 1MB 片内 Flash，不应残留 STM32F10x 算法。
6. 点击 Build（编译），确认 0 Error(s)。
7. 点击 Flash -> Download。下载完按板上的 RST；观察 PC0 旁的指示灯。

当前仅验证编译、下载和基本运行。本工程使用内部 HSI 16MHz，不依赖外部晶振。
预期 PC0 每 500ms 翻转一次电平，一个完整亮灭周期约 1 秒；PWR 电源灯不由程序控制。
照片尚不能确定 PC0 灯的亮灭极性，但周期翻转不依赖高电平亮还是低电平亮。

## 接线

黑色 F407 板由 Type-C 供电，ST-Link 插电脑。
- ST-Link SWCLK -> 板子 CLK
- ST-Link SWDIO -> 板子 DIO
- ST-Link GND -> 板子 GND
板子 Type-C 供电时不接 ST-Link 的 3.3V/5V 输出。
使用正面标有 +5V/GND/DIO/CLK 的一排；背面的 3V3/RST/TXD/RXD 是另一排功能。

## 灯不闪时先观察什么

进入调试后需要运行（Run），暂停状态下灯不会持续闪烁。
Watch 中添加 g_milliseconds、g_led_toggle_count，观察运行一段时间后暂停时数值是否增长。
若变量增长而灯不闪，优先核对 LED 与 PC0 的实际连接，不据此判断整个程序未运行。
若下载时报错，把完整错误和 Flash Download 设置截图保留。

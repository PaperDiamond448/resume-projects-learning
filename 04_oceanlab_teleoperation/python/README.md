# OceanLab-Python 海洋信息实验教学平台

OceanLab-Python是一个用Python开发的海洋信息实验教学平台，用于模拟和控制水池中的水听器和换能器设备。该系统采用主从架构，包含主控终端(Master)和实验池端(Slave)两部分，通过网络进行通信。

## 开发规范

- **功能独立性**：修改A功能时，不得修改除A外的其他部分和功能，不得阉割其他部分模块和代码。
- **沟通规范**：回复问题时需始终保持中文。
- **主从端独立运行**：主从端应该是独立的，而不是相互依赖的。从端可在从端电脑上一天运行超过24h，保持静态状态。
- **正确配对**：用户通过主端登录上线后，可以检测并和从端进行配对，应确保主端与正确的从端配对（如用户预约了实验池1，获得密钥后进入主端，应直接与实验池1的从端配对）。

## 端口管理规范

### 实验池端口分配

为了确保多实验池环境下的通信隔离，系统采用以下端口分配方案：

1. **实验池1**：
   - 主端监听端口：8887, 8888
   - 从端使用端口：8887, 8888
   - 默认IP：localhost

2. **实验池2**：
   - 主端监听端口：8885, 8886
   - 从端使用端口：8885, 8886
   - 默认IP：localhost

3. **实验池3**：
   - 主端监听端口：8883, 8884
   - 从端使用端口：8883, 8884
   - 默认IP：localhost

### 端口管理规则

1. **主端端口限制**：
   - 使用实验池1密钥登录时，只能监听8887和8888端口
   - 使用实验池2密钥登录时，只能监听8885和8886端口
   - 使用实验池3密钥登录时，只能监听8883和8884端口
   - 使用主密钥(1111)登录时，可以选择所有端口

2. **从端端口选择**：
   - 实验池1从端可选择8887或8888端口
   - 实验池2从端可选择8885或8886端口
   - 实验池3从端可选择8883或8884端口

3. **IP地址配置**：
   - 默认使用localhost
   - 支持自定义IP地址配置
   - 主端登录后提供端口和IP配置界面

### 配置界面

主端登录后提供以下配置选项：

1. **端口配置**：
   - 根据登录的实验池自动限制可选端口范围
   - 管理员模式(主密钥)下可选择所有端口

2. **IP地址配置**：
   - 默认值：localhost
   - 支持自定义IP地址输入
   - 实时验证IP地址有效性

3. 安装依赖项：


## 启动方法

### 主控终端(Master)

1. 在Windows系统上，双击`run.bat`启动主控终端
2. 或者通过命令行启动：

   **Linux/Mac 或 Windows CMD：**
   ```
   cd program && python main.py
   ```

   **Windows PowerShell：**
   ```
   cd program; python main.py
   ```
   或分步执行：
   ```
   cd program
   python main.py
   ```

   > **注意**：在Windows PowerShell中不能使用`&&`连接命令，请使用分号`;`或分步执行命令。

3. 使用预约系统获取的实验密钥进行登录
4. 主控终端将自动搜索网络中的实验池设备并与相应实验池配对

### 实验池端(Slave)

1. 在Windows系统上，双击`start_slave.bat`启动实验池端
2. 或者通过命令行启动：

   **Linux/Mac 或 Windows CMD：**
   ```
   cd program && python client/client_app.py --server <服务器地址> --pool-id <实验池ID>
   ```

   **Windows PowerShell：**
   ```
   cd program; python client/client_app.py --server <服务器地址> --pool-id <实验池ID>
   ```
   或分步执行：
   ```
   cd program
   python client/client_app.py --server <服务器地址> --pool-id <实验池ID>
   ```

3. 输入实验池ID和服务器地址（默认为localhost）
4. 实验池端将以静态方式运行，等待主控终端连接

## 使用指南

### 主控终端功能

1. **登录系统**：
   - 启动后需要输入从预约系统获取的实验密钥进行登录
   - 系统会根据密钥自动与相应的实验池配对

2. **连接实验池**：
   - 登录后系统会自动搜索网络中的实验池
   - 系统会根据预约信息与正确的实验池配对

3. **控制水听器和换能器**：
   - 调整水听器和换能器的位置坐标(X,Y,Z)和旋转角度
   - 参数变更会实时同步到实验池端界面上

4. **查看3D可视化**：
   - 切换到"3D视图"标签页查看水池、水听器和换能器的3D模型
   - 可以用鼠标旋转和缩放3D视图

5. **查看摄像头视频**：
   - 切换到"摄像头"标签页查看实验池端的摄像头视频流

6. **查看数据波形**：
   - 切换到"数据波形"标签页查看从端返回的水听器或采集器采集的数据和波形
   - 可以选择不同类型的信号进行模拟：
     - **正弦波**：标准正弦波信号，可调整频率
     - **脉冲波**：短时间脉冲信号，适合模拟声纳脉冲
     - **调频脉冲波**：频率随时间变化的脉冲，适合模拟调频声纳
   - 可以调整信号频率和采样率，观察不同参数下的波形变化
   - 实时显示数据统计信息和波形图

### 实验池端功能

1. **图形界面操作**：
   - 从端提供与主端风格相近的图形界面
   - 显示当前设备状态和来自主端的参数同步信息

2. **连接到主控终端**：
   - 启动时需要输入实验池ID和服务器地址
   - 连接成功后会自动发送状态和视频流到主控终端

3. **执行控制命令**：
   - 接收来自主控终端的参数和命令
   - 控制实际的水听器和换能器设备
   - 界面上实时显示参数变化

4. **数据采集与传输**：
   - 采集水听器或采集器的数据
   - 将数据和波形信息传输至主控终端

## 参数范围

系统支持调整以下参数：

1. **水听器参数**：
   - X坐标：-1m 到 1m
   - Y坐标：-0.25m 到 0.25m
   - Z坐标：0.3m 到 1.0m
   - 旋转角度：0° 到 360°

2. **换能器参数**：
   - X坐标：-1m 到 1m
   - Y坐标：-0.25m 到 0.25m
   - Z坐标：0.3m 到 1.0m
   - 旋转角度：0° 到 360°

3. **水池参数**：
   - 水深：0m 到 1m

## 常见问题

1. **无法连接到实验池**：
   - 检查网络连接
   - 确认实验池ID是否有效（默认有效ID：pool1, pool2, pool3）
   - 确认防火墙是否允许通信（默认端口：8000）
   - 确认密钥是否与预约的实验池匹配

2. **无法显示摄像头视频**：
   - 确认实验池端摄像头是否正常工作
   - 检查网络带宽是否足够

3. **3D视图无法显示**：
   - 确认显卡驱动是否支持OpenGL
   - 尝试更新显卡驱动

4. **参数同步失败**：
   - 检查主从端网络连接
   - 确认从端是否正常运行

5. **无法显示数据波形**：
   - 确认从端的数据采集设备是否正常工作
   - 检查数据传输通道是否畅通

6. **波形图表中文显示为方框乱码**：
   - 这是由于matplotlib无法正确加载中文字体导致的
   - 解决方法：确保添加以下配置代码
     ```python
     import matplotlib
     matplotlib.rcParams['font.sans-serif'] = ['SimHei', 'Microsoft YaHei', 'SimSun', 'sans-serif']
     matplotlib.rcParams['axes.unicode_minus'] = False
     ```
   - 或者安装matplotlib中文字体支持包

## 高级功能

### MATLAB集成

系统支持与MATLAB引擎集成，用于高级信号处理和分析：

1. 确保已安装MATLAB和MATLAB Engine API for Python
2. 系统会自动检测MATLAB引擎，如果可用则使用MATLAB进行仿真和信号处理
3. 如果MATLAB不可用，系统将使用内置的Python模拟引擎

## 开发者信息

系统使用模块化设计，便于扩展和维护。核心模块包括：

- **GUI模块**：负责用户界面和交互，包括主端优化登录界面和从端图形界面
- **通信模块**：处理网络通信和数据传输，确保主从端正确配对
- **渲染模块**：实现3D模型的渲染和可视化
- **模拟引擎**：提供无MATLAB环境下的模拟功能
- **MATLAB接口**：与MATLAB引擎集成，用于高级分析
- **密钥管理**：与预约系统集成，处理实验池预约和密钥验证
- **数据采集与显示**：负责从端数据采集和主端数据波形显示
